# SpendTrack — Financial Intelligence & Expense Dashboard

> **Enterprise-Grade Personal Finance Analytics & Budget Tracking Dashboard**  
> *Engineered by [Deepak Venkata Kumar Konijeti](https://github.com/deepakkonijeti5886-Ui-Design)*  
> Live Demo: [https://deepakkonijeti5886-ui-design.github.io/spendtrack-analytics/](https://deepakkonijeti5886-ui-design.github.io/spendtrack-analytics/)

---

## 💼 Features

- **Interactive Financial Visualizations**: Dynamic SVG income vs. expense area curves with hover tooltips and metric cards.
- **Budget Velocity Monitoring**: Category breakdown with animated status bars and burn-rate warnings.
- **Real-Time Transaction Ledger**: Fast search, filtering, and tag management for monthly expenses.
- **Multi-Currency Support**: Instant currency conversions with localized formats.
- **High-Density Clean UI**: Recruiter-grade fintech aesthetics with dark mode luxury palette.

---

## 🛠️ Tech Stack

- **Frontend**: Vanilla JavaScript (ES6+), HTML5, Tailwind CSS
- **Charts & Motion**: SVG Vector Graphs, GPU-accelerated CSS Transitions
- **State Management**: Reactive LocalStorage state engine
- **Aesthetics**: Premium Dark Theme, Neumorphic Cards, High-Contrast Typography

---

## 🚀 Quick Start

Simply clone and launch in your browser:

```bash
git clone https://github.com/deepakkonijeti5886-Ui-Design/spendtrack-analytics.git
cd spendtrack-analytics
# Open directly in browser:
open index.html # On macOS
start index.html # On Windows
```
